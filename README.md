# Nexus Operativo - Suite de Inteligencia Logística

Bienvenido a Nexus Operativo, una aplicación web construida con Next.js y desplegada en Firebase App Hosting. Esta suite está diseñada para proporcionar herramientas inteligentes que optimizan y analizan las operaciones logísticas.

## Módulos Principales

- **Análisis de Productividad de Empaque:** Analiza datos de remisión para generar reportes detallados sobre el rendimiento de los operarios, la eficiencia por marca y la productividad por hora.
- **Recepción de Mercancía:** Gestiona el proceso de recepción de productos, validando contra una base de datos y registrando novedades.
- **Ventas por Mayor:** Administra pedidos a granel y el proceso de empaque asociado.
- **Y mucho más...**

Esta aplicación utiliza Genkit para sus funcionalidades de IA, ShadCN para los componentes de la interfaz de usuario y Tailwind CSS para el estilo.
